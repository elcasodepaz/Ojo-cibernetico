## 🔧 Instalación
<h3 style="color: red;">Instalación</h3>
<h4>Kali Linux / Parrot OS / Termux</h4>
<pre><code>
git clone https://github.com/elcasodepaz/Ojo-cibernetico.git
cd Ojo-cibernetico/
pip3 install -r requirements.txt
python3 Ojo-cibernetico.py
</code></pre>

<h4>OSX</h4>
<pre><code>
git clone https://github.com/elcasodepaz/Ojo-cibernetico.git
cd Ojo-cibernetico/
pip3 install -r requirements.txt
python3 Ojo-cibernetico.py
</code></pre>

### Linux / Parrot OS / Termux / macOS

> ⚠️ **IMPORTANTE**: Para evitar errores como `externally-managed-environment`, recomendamos usar un entorno virtual.

```bash
# 1. Clona el repositorio
git clone https://github.com/elcasodepaz/Ojo-cibernetico.git
cd Ojo-cibernetico/

# 2. Crea un entorno virtual
python3 -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

# 3. Instala las dependencias
pip install -r requirements.txt

# 4. Ejecuta la herramienta
python3 Ojo-cibernetico.py
```
> 🛑 **¿No quieres usar entorno virtual? (NO recomendado)**  
> Puedes forzar la instalación con:
>
> ```bash
> pip3 install --break-system-packages -r requirements.txt
> ```
>
> ⚠️ **Advertencia**: Esto puede afectar tu entorno de Python del sistema y causar errores con otras herramientas. Úsalo sólo si sabes lo que estás haciendo o en un entorno de pruebas.
